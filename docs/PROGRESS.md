### Phase 1 — Foundation & core (2026-10-28, committed; deployment verification pending)

**Built**
- Backend (`backend/`): FastAPI app, SQLAlchemy models, Alembic migration `0001_core`, Celery worker (heartbeat,
  hourly audit-chain verification, session cleanup), `opsbrain-admin` CLI.
  - Auth: argon2id passwords (hashed off the event loop), server-side sessions (`__Host-` cookies, SameSite=Strict),
    CSRF double-submit header, TOTP MFA with replay protection, per-account lockout, per-IP rate limit (Valkey),
    forced password change, MFA policy (none/admins/all), session idle + max lifetime.
  - RBAC: 28 permissions, 6 built-in roles (Admin always has every permission, incl. future ones), custom roles,
    guard against removing the last Admin.
  - Audit: append-only table (runtime DB role lacks UPDATE/DELETE/TRUNCATE; trigger blocks every role), SHA-256 hash
    chain, verify endpoint, filters, CSV export; denials and failed logins are audited.
  - Settings registry (typed + validated), platform health (DB, Valkey, worker, audit chain, backup, TLS), modules
    endpoint reading `/etc/opsbrain/state/modules.json`, Prometheus metrics (internal only).
- Frontend (`frontend/`): React/TS/Vite/Tailwind. Sign-in flow (password → MFA / forced password change / MFA
  enrolment with QR), full PDF §13 navigation filtered by permission, Logging/Monitoring open-in-new-window
  workspaces, Overview (modules + health), My account, Users, Roles & RBAC matrix, Audit Logs, System Settings.
  Unbuilt pages show an honest "not available yet — phase N" notice.
- Deploy (`deploy/core/`): compose (postgres+pgvector, valkey, migrate job, api, worker, Caddy web), non-root,
  cap_drop ALL, read-only FS for app containers; Caddy TLS 1.2/1.3 + security headers + `/api/metrics` blocked;
  Postgres init creates owner + least-privilege app roles.
- `scripts/opsbrainctl`: install/status/upgrade/backup/restore/remove(+purge)/cert/admin/restart/verify-audit/logs.
  Internal CA + server cert, generated secrets (0600), restic backups with retention + status file, restore with
  safety backup and typed confirmation, purge with typed confirmation and final backup, systemd timers.
- Docs: README, install guide, user guide, troubleshooting guide. CI workflow (`.github/workflows/ci.yml`).

## Conventions for future sessions
- Never write files through Python `pathlib.write_text` on Windows (it emits CRLF). Use the editor tools or
  `open(..., newline="")`. `.gitattributes` enforces LF in the repo; shell scripts must be LF in the working tree
  too because Docker Desktop bind-mounts them.
- Git Bash: native Windows openssl mangles `/O=...` subjects; tests set `MSYS2_ARG_CONV_EXCL="/O="`.
